Update circle_users.json on GitHub

Step-by-Step Guide:

1

Download the updated JSON

Click "Export JSON" button to download the latest circle_users.json file.

2

Go to your GitHub repository

Navigate to your GitHub repo where this app is hosted.

3

Upload the file

Click "Add file" → "Upload files" → Select the downloaded circle_users.json → Commit changes.

4

Wait for deployment

GitHub Pages will automatically deploy the update (takes 1-2 minutes).

Important Note

Until you upload the updated JSON to GitHub, new profiles are only visible to you (stored in your browser). To share them with all users worldwide, you must update the file on GitHub.
